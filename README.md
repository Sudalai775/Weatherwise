# 🌦️ WeatherWise

### Smart Weather Forecasting & Climate Awareness Platform

WeatherWise is a responsive weather forecasting web application that provides real-time weather information, temperature updates, humidity levels, and location-based forecasts through an intuitive user interface. The project was inspired by the growing impact of climate variability and the need for accessible weather information.

## 🚀 Live Demo

https://predictionweather.iceiy.com/

## ✨ Features

* 🌍 Real-time weather forecasting
* 📍 Location-based weather information
* 🌡️ Temperature monitoring
* 💧 Humidity tracking
* ☁️ Current weather conditions
* 📱 Fully responsive design
* ⚡ Fast and lightweight interface

## 🎯 Project Objective

The goal of WeatherWise is to make weather information simple, accessible, and useful for everyday decision-making. The platform helps users stay informed about changing weather conditions through accurate and easy-to-understand forecasts.
